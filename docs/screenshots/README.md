# Screenshots

Placeholder folder for README screenshots. Capture these views from a running
app (`npm run dev`) and save them here with matching names:

- `dashboard.png` — main dashboard (today's habits, streak ring, freeze bank)
- `habit-detail.png` — habit detail page (heatmap, streak history)
- `analytics.png` — analytics page (charts and year heatmap)

Dark theme, 1440×900 or similar.
